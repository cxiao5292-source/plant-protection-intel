# 全球与植保情报站

A Chinese mobile-friendly daily intelligence digest for global news, plant protection research, overseas visa policies, and agrochemical jobs.

## Data
- Public Google News RSS search results are used for discovery.
- Daily update schedule: 00:15 UTC (08:15 China Standard Time).
- Daily snapshots are saved under `data/archive/YYYY-MM-DD.json`.
- RSS headlines are not official policy advice or confirmed vacancies. Always verify with the original government or employer source.

## GitHub Pages
In repository Settings → Pages, set Build and deployment Source to **GitHub Actions**. The repository must be public for the intended free public Pages hosting.
